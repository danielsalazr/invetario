Guía de nomenclatura

¿Dónde está el artículo que buscas? La nomenclatura te indica el camino hasta su ubicación o caja. Aquí aprenderás a leerla y a reconocer qué cambia cuando mueves un contenedor.

1. Empieza por la bodega

La bodega se muestra por separado. Confirma que estás mirando la correcta: dos bodegas pueden tener una ubicación llamada 100_1_2.

En Almacenar y Picking eliges la bodega de trabajo. En Traslados eliges la bodega de destino; el origen puede estar en otra bodega.

2. Lee el camino de izquierda a derecha

Cada guion bajo _ separa un nivel. Los números corresponden a ubicaciones fijas y la letra C identifica un contenedor.

100_1_2_C4
Estante 100 → Panel 1 → División 2 → Contenedor C4

Si encuentras esta nomenclatura junto a un artículo, sus existencias están registradas directamente en la caja C4. Si la ubicación no tiene panel o división, el camino tendrá menos segmentos.

Una ubicación fija puede ser un estante, una estiba, un panel o una división. Un contenedor puede ser una caja u otro recipiente que puedes mover.

3. Cada caja conserva su código

C4 significa «contenedor con ID 4». La aplicación asigna el código al crear la caja. No tienes que escribirlo ni cambiarlo: esa caja seguirá siendo C4 aunque la lleves a otra ubicación o bodega.

Los códigos pueden tener saltos; no hace falta que estén en orden consecutivo. Puedes darle un nombre fácil de reconocer, como «Tornillos pequeños», para acompañar su identificación.

4. Una caja puede estar dentro de otra

Si colocas C9 dentro de C4, ambas aparecen en el camino. El último código identifica la caja donde está registrado el artículo.

100_1_2_C4_C9
Estante 100 → Panel 1 → División 2 → Caja C4 → Caja C9

Para encontrar ese artículo, llega a la división 2, busca C4 y abre la caja C9 que está dentro. Si mueves C4 completa, C9 y el contenido de ambas se mueven con ella.

Una caja que está directamente en la bodega, sin ubicación padre, se muestra con su código, por ejemplo C4. Si contiene C9, el camino es C4_C9.

5. ¿Qué pasa cuando mueves una caja?

Su código permanece igual y su nomenclatura se actualiza para señalar la nueva posición. Supongamos que llevas C4, con C9 dentro, a la ubicación 101_2_1:

Ejemplo de traslado de una caja completa
CajaAntesDespués
C4100_1_2_C4101_2_1_C4
C9, dentro de C4100_1_2_C4_C9101_2_1_C4_C9

El camino cambia porque las cajas están en otro sitio. Sus códigos y las cantidades almacenadas se conservan. También puede cambiar la parte numérica si se reorganizan las ubicaciones fijas.

6. Elige la operación que necesitas

  • Para ingresar unidades: usa Almacenar.
  • Para retirar unidades: usa Picking.
  • Para mover unidades de un artículo: usa Traslados. Puedes moverlas entre ubicaciones y contenedores.
  • Para mover una caja completa con todo su contenido: entra a Gestión de ubicaciones, selecciona el contenedor y utiliza su opción de traslado.

En las tablas de existencias, Ubicación / caja muestra la nomenclatura completa y Ruta muestra el camino con nombres. Haz clic en la fila para seleccionar esa posición.

Recuerda: el código te dice qué caja es; la nomenclatura y la bodega te dicen dónde encontrarla.
